
# Data Mining

## Project Overview

This repository contains my coursework and practical assignments in Data Mining.

The main goal is to explore data analysis techniques, understand patterns in datasets, and develop practical skills in working with data using Python.

## Repository Structure

| File | Description |
|---|---|
| `heart.csv` | Dataset used for data analysis and practical exercises |
| `lab1.ipynb` | Laboratory assignment 1 |
| `lab2.ipynb` | Laboratory assignment 2 |
| `lab4.ipynb` | Laboratory assignment 4 |

## Tools & Technologies

- Python

- Seaborn
- Scikit-learn

## Topics Covered

- Data preprocessing

- Data Mining techniques

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```
2. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```
3. Open the project in Jupyter Notebook.
4. Run the notebooks to explore the assignments.
